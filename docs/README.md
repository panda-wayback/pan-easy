# baidu-easy

## 目标

把百度网盘命令行工具 bdpan 封装成 HTTP API，打包进 Docker 镜像。其他程序通过网络调用就能操作百度网盘，不需要在自己的机器上安装 bdpan。

## 要实现的

- 使用者：需要读写百度网盘的其他程序（脚本、服务、定时任务），服务部署在服务器或 NAS 上。
- 能力：通过 HTTP 完成网盘操作：查看列表、搜索、上传、下载、转存、分享、建目录、移动、复制、重命名、删除，以及查看登录状态。
- 上传：调用方把文件内容放在请求里发送。
- 下载：服务把文件内容直接返回给调用方。
- 传输方式：调用方不需要和容器共享目录。上传、下载接口是同步请求，暂不做断点续传；分享下载是后台任务。
- 分享下载：粘贴百度网盘分享文字（含链接和提取码），服务自动识别并在后台把文件下载到服务器的下载目录；提交后返回任务 ID，按 ID 可查看任务进度、下载速度、已下载/总大小、剩余时间、状态、服务器上的保存位置、网盘中的保存位置和失败原因。任务按提交顺序逐个执行；文件会先转存到"我的应用数据/bdpan/<日期>/"并保留；任务历史保存在持久存储中，重建容器、服务重启后保留；重启时未完成的任务标记为已中断，需要时重新提交。
- 登录：通过 API 完成，分两步：获取授权链接、提交授权码。调用方必须显式确认 bdpan 安全须知。只需登录一次；重建容器、升级镜像后登录状态保留。
- 账号：一个容器对应一个百度网盘账号。
- 访问控制：调用方必须携带访问密钥；没有密钥或密钥错误时拒绝请求。
- 测试网页：服务自带一个简单网页，左侧边栏切换两个页面：下载页（粘贴分享文字下载、查看任务）和登录页（访问密钥、登录状态、授权登录）。网页上输入访问密钥后才能使用，页面只调用本服务的 API。
- 返回：统一 JSON 格式。成功时透传 bdpan 的结果（包括保存路径、查看链接）；失败时带上 bdpan 的错误码和原因。
- 凭据：只存放在持久化存储里，不打进镜像，也不通过 API 返回。
- 平台：支持 linux/amd64 和 linux/arm64。
- 版本：镜像内固定 bdpan 版本；不提供更新接口，升级就是重建镜像。
- 网盘范围：沿用 bdpan 默认限制，只操作"我的应用数据/bdpan"。
- 失败处理：
  - 未登录：返回明确的"未登录"错误，提示调用登录接口。
  - Token 失效：返回"需要重新登录"错误。
  - 授权码错误或过期：返回原因，需要重新获取授权链接。
  - 转存任务未完成：返回"已提交"状态和任务 ID，不当作成功。
- 不做：面向普通用户的完整网盘界面；宿主机 Agent（Cursor skill）改为调用本服务；会员、AI PPT 等非文件操作。

## 解决步骤

1. 镜像：基于精简 Linux 基础镜像，构建时安装固定版本的 bdpan 并做完整性校验；API 服务和 bdpan 在同一个镜像里运行。→ [spec.yaml](../spec.yaml)
2. API 服务：把每个请求转成一次 bdpan 命令调用（使用其 JSON 输出），再整理成统一格式返回。→ [app/bdpan/spec.yaml](../app/bdpan/spec.yaml)、[app/api/spec.yaml](../app/api/spec.yaml)；访问密钥校验并入接口模块。
3. 登录与凭据持久化：bdpan 的配置目录使用持久卷；登录接口内部依次调用 bdpan 的"获取授权链接"和"提交授权码"。→ [app/api/spec.yaml](../app/api/spec.yaml)；登录逻辑并入接口模块。
4. 文件传输：上传时，先把请求里的文件暂存到容器内的临时目录，再交给 bdpan；下载时，先让 bdpan 下载到临时目录，再返回给调用方；完成后清理临时文件。→ [app/api/spec.yaml](../app/api/spec.yaml)；下载只支持单个文件。
5. 测试网页：由 API 服务直接提供静态页面，和 API 使用同一端口；不引入单独的前端构建流程。→ [web/spec.yaml](../web/spec.yaml)
6. 分享下载：从文字中提取分享链接和提取码，加入任务队列；后台逐个调用 bdpan 下载到挂载的下载目录，并从 bdpan 的进度输出中读取进度。→ [app/tasks/spec.yaml](../app/tasks/spec.yaml)
