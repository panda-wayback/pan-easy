# 对外下载服务

## 目标

提供一个面向付费用户的独立下载网站：凭卡密粘贴百度网盘分享链接下载，用户接触不到管理页、主密钥与 baidu-easy 本身。

## 需求

- 网页任何人都能打开；没有可用的卡密时不能提交
- 卡密为 spark-auth 的按次数卡密，每次提交扣 1 次
- 卡密记在本浏览器：提交成功（核销成功）后保存，下次打开首页自动填入，输入框始终以密码形式遮挡；卡密无效、次数已用完、不是按次数卡密、已停用时自动清除已保存的卡密
- 卡密输入框旁有「清除」按钮：清空输入框并删除本浏览器保存的卡密；输入框下提示「卡密保存在本浏览器，公共电脑用完请清除」
- 分享文字中没有百度网盘分享链接、或没填卡密时直接提示，不扣次数
- 卡密不可用时不创建任务，并按原因提示：卡密无效、次数已用完、不是按次数卡密、卡密已停用、卡密服务暂不可用
- 首页：输入卡密、粘贴分享文字（链接，可含提取码）提交；提交成功后跳转到该任务的专属页面，页面上显示本次提交后卡密剩余次数
- 专属页面：每次提交生成一个网址，打开无需输入任何信息，显示分享链接、状态、进度、速度、已下载/总大小、剩余时间、失败原因；未结束时自动刷新；完成的单文件任务有「下载文件」与「复制链接」，多文件任务提示暂不支持；有返回首页的按钮，方便下次提交；不显示卡密
- 专属页面上任务失败或中断时显示「重试」与剩余重试次数：用原分享链接重新下载，不核销卡密、不扣次数；每个专属页面最多重试 3 次；重试后网址不变，页面继续显示新任务的进度与下载按钮
- 专属页面提交后 24 小时过期；重试不延长过期时间；在其中生成的下载链接不晚于页面过期
- 首页列出本浏览器提交过且未过期的专属页面（历史）
- 用户看不到其他人的任务；baidu-easy 的管理页、`/api/*` 与主密钥对外不可见

## 方案

- 新增：Module `shop`，独立进程（Python + FastAPI，与 baidu-easy 打包在同一镜像，见 [Docker 镜像](../image/README.md)）：提供网页与任务接口；提交时服务器端先调用 spark-auth 核销接口 `POST /api/redeem` 扣 1 次，成功后再用主密钥调用 baidu-easy 创建任务
- 复用：`app/api` 的 `POST /api/tasks`、`GET /api/tasks/{id}`、`POST /api/tasks/{id}/link`、`GET|HEAD /dl/{id}`、`POST /api/tasks/{id}/retry`
- 修改：`shop` 新增专属页面重试接口；专属页面的任务、下载链接与下载都改为指向该页面当前（最近一次重试）的任务
- 修改：镜像 `/data` 新增 shop 的重试记录文件（页面对应的当前任务与已重试次数），重建容器后仍在
- 配置：`SPARK_AUTH_URL` 为 spark-auth 服务地址；本地调试时 shop 在容器内，填 `http://host.docker.internal:8000`
- 部署：容器内 8080 为管理页，compose 只绑定 `127.0.0.1:28080`；8081 为 shop，对外暴露 28081
- 取舍：shop 是独立进程而非在 baidu-easy 内加公开页，baidu-easy 代码保持不变，卡密、用户隔离都只改 shop
- 取舍：用按次数卡密而非设备激活卡密：网页读不到设备硬件标识，按次数不绑定设备，与「下载一次」的售卖方式一致
- 取舍：先核销再创建任务（spark-auth 规定）；核销前只检查文字中有 `pan.baidu.com/s/` 链接，链接失效、提取码错误等要下载时才知道，任务失败不退次数
- 取舍：剩余次数随提交结果记在浏览器历史里，专属页面从本浏览器历史读取；在别的浏览器打开专属页面时不显示
- 取舍：专属页面网址自带签名凭证（任务 ID + 过期时间），不需要存储；网址里不含卡密，转发网址不会泄露卡密
- 取舍：历史只保存在浏览器本地，不提供列出全部任务的接口
- 取舍：卡密存浏览器本地存储（关闭浏览器后仍在）而非只在当前标签页：用户每次来都不用重填；只在核销成功后保存，输错的卡密不会被记住；卡密仍只在提交时发给 shop，不出现在网址、专属页面与历史记录中
- 取舍：重试次数记在服务器端而非凭证里：凭证里的次数可以用旧网址绕过；重试只能重下同一个分享链接，所以不扣次数，用每页 3 次上限防止坏链接反复占用下载队列
- 取舍：所有失败都允许重试：bdpan 的错误码无法可靠区分提取码错误、链接失效与系统故障，由次数上限兜底
- 取舍：只提供手动重试，不自动重试：由用户判断是否值得再试，避免对失效链接自动重复下载

## 不做

- 设备激活卡密
- 跨设备同步历史
- 多文件打包下载
- 自动重试；重试退还或补偿卡密次数
