# 公开下载页

## 目标

提供一个与管理页分开的独立网页，只做一件事：粘贴百度网盘分享链接下载，查看进度，完成后拿到下载链接。

## 需求

- 输入访问密钥，保存在浏览器本地
- 粘贴分享文字（链接，可含提取码）提交下载
- 任务列表：状态、进度、速度、已下载/总大小、剩余时间、失败原因；有未结束任务时自动刷新
- 完成的单文件任务：「下载文件」与「复制链接」；多文件任务提示暂不支持

## 方案

- 新增 Module `web-public`：单文件静态页面，调用现有 `/api/tasks*` 接口，不改后端接口
- 服务在 `GET /public` 提供该页面
- 不含网盘管理、bdpan 登录、重试、删除

## 不做

- 卡密激活（以后替换访问密钥输入）
- 用户之间的任务隔离
