# 分享下载

## 目标

粘贴百度网盘分享文字，服务自动识别链接和提取码，在后台把文件下载到服务器下载目录。

## 需求

- 提交后返回任务 ID，按 ID 可查看进度、下载速度、已下载/总大小、剩余时间、状态、服务器保存位置、网盘保存位置和失败原因；多文件时进度字段为整包汇总（已完成文件之和 + 当前文件已下），不是单个文件
- 只读预览（供计费等）：transfer list 递归展开分享内目录后返回全部文件总大小与文件名列表
- 任务执行前按磁盘文件比对做本地缓存（不依赖任务历史与 task_id）：单文件在 `downloads/*/文件名` 找同名同大小；多文件扫 `downloads/*.zip`，只读 zip 中央目录，成员名+大小与分享中全部文件条目完全一致则命中；命中后 `saved_to` 指向已有路径，不再查询网盘、转存与下载
- 本地未命中时在自己网盘 /apps/bdpan/ 下查同名同大小文件：命中则免转存、直接从网盘下载；否则才转存，转存阶段同一账号同时只进行一个（百度账号限制）
- 转存若因「自己分享的链接」（errno 13045）失败：在整个网盘按同名同大小查找分享中的全部文件，全部找到则直接从网盘路径下载，不再转存；找不到则仍按原错误失败
- 免转存或转存完成后、真正下载前，只与未结束任务做重叠判定（queued / running / submitted）：分享链接相同，或分享条目逐个同名且同大小即判为重叠；重叠任务的专属页面直接展示被重叠任务的实时状态与结果，其下载链接指向同一份文件；部分重叠不合并；已完成任务不参与合并，文件复用只走本地缓存
- 下载阶段最多 N 个任务同时进行，N 默认 2，可通过环境变量 `BAIDU_EASY_MAX_DOWNLOADS` 调整（设为 1 即恢复逐个执行）；等待网盘转存结果期间不占用下载并发名额
- 单次任务大小上限、按任务腾空间与冷文件清理见 [下载空间控制](../download-space/README.md)
- 文件先转存到应用目录下的中性路径并保留（自己分享链接走网盘直下时不转存）：相对路径 `整理/<YYYYMM>/<6 位随机>/`（例：我的应用数据/bdpan/整理/202610/a3f9c2/）；不出现 task_id、日期连写、bdpan/baidu-easy 等工具字样；根目录名 `bdpan` 为百度开放平台应用沙箱固定，无法改名
- 分享含目录时：转存（或免转存定位）后递归列出目录内文件再下载；展开后仅一个文件按单文件交付，多个文件打 zip；展开为空则失败
- 本地下载按「总大小 / 任务 ID」写入：工作目录 `downloads/<总字节>/<task_id>/`；单文件落在该目录；多文件打成并列的 `downloads/<总字节>/<task_id>.zip`；复用时不拷贝，直接指向已有交付物；总大小取展开后的文件 size 合计
- 真正开始下载前才创建工作目录；若目录已存在则先检查内部：空则删掉重建，有残留则清空后再下；每个文件下完后校验本地文件存在且大小相符；多文件无任何可打包文件时任务失败并清掉空目录，不标记为已完成 zip
- 多文件交付物只认通过校验的 zip：打包后读中央目录核对成员名+大小；`saved_to` 不得指向工作目录/空目录；复用前同样校验 zip 内部
- 多文件 zip 在临时目录生成后再移入，只含本次文件，避免边压边把 zip 打进自身卡死
- 已完成且只有一个文件（含多文件打成的 zip）的任务，可按 ID 生成带有效期的下载链接（默认 24 小时，最长 7 天）；持链接不带密钥可直接下载，支持断点续传
- 任务历史持久化，重建容器、服务重启后保留；重启时未完成的任务标记为已中断，需要时重新提交

## 方案

- 复用：`app/tasks` 的任务队列，见 [`app/tasks/interface.yaml`](../../../app/tasks/interface.yaml)
- 复用：`app/api` 的 `/api/tasks*` 与 `/dl/{id}`，见 [`app/api/interface.yaml`](../../../app/api/interface.yaml)
- 修改：`app/tasks` 布局为 `<总大小>/<task_id>/` 与 `<总大小>/<task_id>.zip`；网盘转存目标改为 `整理/<YYYYMM>/<6 位随机>/`；目录分享转存后递归展开再下载；本地缓存扫盘文件比对；下载前清理空/脏工作目录；下完校验文件；转存 13045 全盘直下；进度整包汇总；zip 临时目录线程打包
- 取舍：第一层 size 方便浏览与核对计费，task_id 防撞车；复用只认交付物内容
- 取舍：网盘路径用「整理/月份/随机」代替「日期/task_id」：仍可按月清理、批次隔离，外观更像个人整理、降低工具痕迹；应用根目录名 bdpan 无法改（开放平台沙箱）
- 取舍：转存前仍在整个 `/apps/bdpan/` 下按同名同大小去重，命中则免转存，避免同内容再占一份
- 取舍：多文件去重要求分享中全部文件都命中才免转存；只命中部分时仍整包转存到新随机目录（可能与旧目录有部分重复），不拆包、不跨目录拼文件，避免半套路径难维护
- 取舍：目录分享不整目录当本地路径打包，而是展开为文件再下；展开后单文件不打 zip，避免「下载完成但本地没有可打包的文件」
- 取舍：工作目录延后到下载前创建，避免转存/合并短路后留下空目录
- 取舍：多文件 zip 比对只读中央目录、不解压；完成与复用都要过同一套成员校验，避免把空目录或未打包路径当成完成物
- 取舍：自己分享不能转存是百度限制，只能从网盘已有路径下载；全盘搜索不限 `/apps/bdpan/`，因用户原文件可能在任意目录
- 取舍：单文件显式传完整本地文件路径，避免 bdpan 把已存在的目录当成 rename 目标
- 取舍：进度回调不同步写盘：bdpan 高频刷进度时写 tasks.json 会占满事件循环，导致管理页无响应
- 取舍：多文件进度按分享条目 size 汇总，避免串行下载时界面只显示最后一个文件
- 取舍：多文件对外仍提供一个 zip，不逐文件扣次；zip 与工作目录并列，避免打进自身
